# 白色手势开屏

开屏组件位于 `apps/mobile/src/features/startup/startup-splash.tsx`，时间轴计算位于同目录 `startup-motion.ts`。图片直接复用应用当前的 `assets/adaptive-icon.png`，没有新增视频播放模块或其他依赖。

## 启动衔接

1. 使用原生顶层 Modal 显示白色遮罩及当前手势图标，避免被原生导航页面或启动屏覆盖。遮罩拦截触摸，状态栏使用深色图标。
2. Modal 的 onShow 确认窗口已展示、布局和图片加载结束后直接隐藏 Expo 原生启动屏并启动帧时钟，不等待系统设置查询或资料加载。第一帧回调作为三秒动画的计时起点。原生启动屏关闭自身退出淡出，防止两段动画重叠。
3. 动画只播放一次，共 3 秒：手势轻点 → 图标底板展开为白色确认条 → 加载弧线变为对勾 → 显示“到点 / 轻点，即到。” → 收回手势图标。
4. 播满三秒后直接关闭动画窗口，进入登录页或主页面。开屏不等待资料加载，也不继续停留在静态末帧；资料尚未就绪时由已有页面显示读取状态。
5. 按用户要求始终播放：开屏不读取系统“减少动态效果”或动画缩放设置，没有静态替代、跳过或缩短播放分支。逐帧计算图标和容器形态，不使用受系统动画缩放影响的 Animated.timing。
6. 每次应用进程冷启动时播放一次；切到后台再回来不重播。进程被关闭或被系统回收后重新打开时，新根布局会重新播放。没有安装后首次打开的持久标记。
7. 组件卸载时取消帧回调。动画窗口关闭后，状态栏恢复当前页面的主题。

## 画面与布局

背景与变形容器固定为纯白，手势、文字、加载弧线和对勾固定为黑色。全程沿用一个容器。宽高、圆角、图标尺寸和位移使用闭式弹簧阶跃响应；每帧直接由已流逝时间计算，可跳帧而不累积误差。确认文字退场后才出现品牌标题。

常规手机上初始图标为 160 dp，小屏幕与横屏缩放以保持边距。中文使用系统字体；等待提示至少 13 dp，副标题至少 12 dp。动画进度由单独的 requestAnimationFrame 时钟驱动。

## 验证

`bun run typecheck` 验证原生组件及项目类型；`bun run test` 覆盖三秒时间轴、末帧图标、文字切换、乱序取帧及窄屏/横屏边界，以及窗口首帧延迟、播放取消、一次性完成回调、实际播放经过变形与品牌画面，同时运行已有业务测试。隔离组件事件验证确认播完切到后台再返回不重播，新根布局冷启动会重新完整播放；该验证不替代 Android 原生绘制测试。

设备检查未发现连接的 Android 手机，当前不能替代真机冷启动、系统动画关闭时播放、后台返回和首页交接的验收。打包按 `docs/android-apk-build.md` 使用标准脚本，不将生成目录的临时改动作为源码修复。
