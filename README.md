# 到点（Diandao）

到点是单设备 React Native + TypeScript 学习通签到工具。登录后可查看课程与签到活动、管理代签账号，并按账号查看签到结果。应用直接调用学习通 HTTPS 接口，账号资料加密保存在本机。本项目为独立工具，非学习通官方应用。

## 下载与安装

- [下载最新版 Android arm64 APK](https://github.com/Asuka01124/diandao-chaoxing/releases/latest)。当前项目版本为 **v1.1**（下载链接指向最新已发布版本）。
- 在 Android 手机上安装 APK，首次打开按提示登录学习通账号。普通使用无需安装 Node.js、Bun 或 Android SDK。
- 应用包名为 `dev.local.sign.tool`；使用相同签名的旧版可以覆盖安装。

## 使用方式

1. 首次登录的账号是主账号，用于读取课程；在「代签」页添加其他账号，并可检查登录状态、重新登录或删除。
2. 在「课程」页选择列表或网格布局，点右上角图标刷新课程。刷新时会检查签到活动，将有进行中签到的课程置顶，其余课程保持原顺序。进入课程后，可在页面右上角刷新签到活动。
3. 打开进行中的活动，查看要求并选择参与账号。按活动类型填写签到码、绘制手势、扫描二维码、选取位置或照片，再提交签到任务。
4. 在「任务」页查看每个账号的执行结果；失败或等待输入的账号可在任务详情中继续处理。照片签到可直接选用预留照片，也可拍照或从相册选择。

底部四个主页面支持左右滑动切换。设置页可切换外观、管理常用位置，以及预留最多 10 张可自定义名称的照片。常用位置和预留照片轻点可更改，长按可打开管理菜单。

## 开发与构建

要求 Node.js 22.13+、Bun 1.3+，以及用于构建客户端的 Android SDK 或 iOS 开发环境。地图使用高德地图 SDK；手机上的地图和地址查询需要网络。

```powershell
bun install --linker hoisted
bun run typecheck
bun test
```

Windows 构建 Android APK 请使用 [`scripts/build-android-apk.ps1`](scripts/build-android-apk.ps1)；已遇到的路径、缓存和签名问题记录在 [`docs/android-apk-build.md`](docs/android-apk-build.md)。

接口研究参考了 [ChaoxingSignFaker](https://github.com/aquamarine5/ChaoxingSignFaker) 的公开协议行为；该项目采用 AGPL-3.0。本仓库没有收录其 Kotlin 源文件，`packages/provider-adapter` 使用 TypeScript 实现接口调用。每次请求关闭系统共享 Cookie，并按账号手动附加会话 Cookie；学习通子域共享当前账号的登录 Cookie。动态二维码含有 `c` 参数时，提交前会调用第三方 `signDetail` 检查是否过期。

启动移动端：

```powershell
bun run --cwd apps/mobile android
bun run --cwd apps/mobile start
```

`ios` 脚本需要 macOS。项目采用 Expo development build；增加原生依赖后需重新构建客户端。

## 功能与数据处理

- 首次登录页的账号为主账号；账号页添加的是代签账号。账号资料使用本地 AES-GCM 加密文件与 SecureStore 密钥保存；支持单独删除、重新授权和会话恢复。
- 独立 Cookie 会话、带课程封面的课程列表；课程支持列表和网格布局。活动按进行中和已结束分组，支持查看详情、更新状态及登录过期重登。
- 单击、位置、照片、二维码、数字签到码、手势签到的输入校验及逐账号任务。手势使用图形控件输入；数字签到码要求 4 至 12 位数字。可在设置中预留最多 10 张照片并自定义名称；照片签到和失败重试可直接在当前页面选择预留照片，也可拍摄或从相册选择。照片活动要求位置时可一并填写。
- 临时签到照片按设置的 1 或 24 小时保留期限清理；预留照片保存在本机，直到手动删除。
- 任务状态持久化，单账号失败不阻断其他账号；提交超时和重启恢复时先查远端状态。动态二维码保存相机实际扫描时间，过期可重新扫码续签。
- 进入位置地图时自动请求系统定位权限并定位到手机当前位置，也可以在地图上重新选点；首次使用高德地图需同意其隐私政策。活动详情展示签到与签退关系，可打开已发布的关联签退。课程页不显示群聊。
- 到点开屏以当前手势图标播放 3 秒纯白变形动画：轻点、展开确认条、加载弧线变为对勾，再收回图标。原生顶层动画窗口显示、图标加载完成后，从首帧开始无条件播放完整 3 秒，播完直接进入应用；每次冷启动播放一次，从后台返回不重播，不受系统“减少动态效果”或动画缩放设置影响。四个主页面支持手势切换和亮色、暗色外观。
- 验证码与人脸要求进入等待状态。人脸可为当前账号单独拍摄或选择授权照片，由第三方接口校验后提交；也可在官方客户端人工完成并返回任务页核查。验证码通过官方客户端人工完成后核查。
- 活动缓存按账号隔离；Tamagui 支持跟随系统、亮色、暗色主题切换。
- 严格的第三方响应解析、HTTPS 限制、请求体与频率限制、整次操作超时取消、默认关闭敏感日志。

## 当前边界

- 第三方接口并非官方稳定 API。本实现使用脱敏响应夹具验证接口行为。接口变化会返回 `PROVIDER_CHANGED`，不会把未知响应当作成功。
- 应用内验证码提交尚未接入，需在官方客户端人工完成。人脸材料上传与签退协议尚待真实活动验证。
- 已完成 Android arm64 APK 本地构建和签名验证；本环境没有连接真机，真实账号与真实活动的端到端流程尚未验证。
- 测试课程已从正式版移除；应用中的签到操作应以真实课程活动为准。
- 单设备模式没有数据库、后台任务或跨设备同步。手机直接调用第三方 HTTPS 接口。

## 目录

- `apps/mobile/app`：首次登录、课程、账号、任务、设置和签到页面。
- `apps/mobile/src/features/accounts`：账号登录、会话验证与删除逻辑。
- `apps/mobile/src/core`：学习通调用入口、加密存储、任务队列与照片暂存。
- `apps/mobile/src/ui`：页面布局、控件和状态组件。
- `packages/provider-adapter/src`：按会话、登录、课程、活动、签到和媒体上传拆分的第三方协议模块。
- `packages/shared`：共享模型与输入校验。
